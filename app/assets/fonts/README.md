# Fonts

Static instances cut from the variable fonts in [google/fonts](https://github.com/google/fonts)
(fontTools `varLib.instancer`). All three are under the SIL Open Font License 1.1; the license
texts are in this folder. The same instances, as WOFF2, are in `web/src/fonts/`.

| File | Family | Use |
|---|---|---|
| `TiltNeon-Regular` | Tilt Neon | Logo and big moments only |
| `BigShouldersDisplay-ExtraBold`, `-Black` | Big Shoulders Display | Headings, numbers, scores |
| `Manrope-Regular`, `-SemiBold`, `-ExtraBold` | Manrope | Questions and everything else |
